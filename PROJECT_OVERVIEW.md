# Project Overview

Dojo Admin is a web app built with Python, FastAPI as a backend and React as its frontend. This application is responsible for the management of an Aikido Dojo. It deals with students (athletes) admission, subscription, classes, instructors and belt exam management.

## Tech stack

- **Language:** Python 3.13 (backend), TypeScript (frontend)
- **UI Framework:** React
- **Architecture:** Backend (kubernetes) + Frontend
- **Database:** MySQL
- **Deployment:** Kubernetes (OKS)
- **CI/CD:** GitHub Actions
- **Testing:** Pytest (backend), Jest (frontend), Cypress (e2e), Behave (BDD, backend)
- **Linting:** Ruff + Pylance (backend), ESLint (frontend)
- **Code formatting:** Ruff (backend), Prettier (frontend)
- **Documentation:** Markdown files in the repository, auto-generated API docs (backend)
- **Code Organization:** Monorepo with separate directories for backend and frontend code
- **Code Architecture:** Clean architecture with clear separation of concerns, modular design, and layered structure
- **Version Control:** Git with feature branches and pull requests
