# Release Notes — PR-1 Pre-Checkin

## Added

- Public pre-check-in confirmation and cancellation before scheduled dojo events.
- Instructor confirmation counts and confirmed-student rosters in Events.
- Configurable minimum belt eligibility for events.
- Physical check-in conversion of valid pre-check-ins, without treating confirmation as attendance.

## Safeguards

- One-hour cutoff, event-state validation, credential-safe public responses, rate limiting, and duplicate-attendance protection.
